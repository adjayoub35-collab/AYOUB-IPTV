# AK4 IPTV — Phone + Android TV

نسخة خفيفة للبناء على الهاتف، وتعمل أيضًا على Android TV / Google TV.

- الشعار: AK4 IPTV
- الهاتف: واجهة لمس.
- التلفزيون: واجهة كبيرة مع أزرار قابلة للتحكم بالريموت (D-pad).
- يدعم M3U وروابط البث المباشر.

## البناء
افتح المشروع في AndroidIDE ثم شغّل: `./gradlew assembleDebug` أو استخدم Quick Run.
